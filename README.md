# Contrast Shower Timer

Initial version copied from [the published app](http://dmitrijv.se/projects/shower/)
on 2026-09-17.

Open `index.html` in a browser. No installation or build is required.

The timer runs three cycles of three minutes hot and one minute cold, with sound
alerts at automatic stage transitions. The **Stage** arrows move backward or
forward silently, restarting the destination stage. **Stop** resets the timer.
It requests a screen wake lock when supported.
